## ABOUT / 我在做什么

我关注 AI 能力如何进入完整的产品流程：让模型看懂图像、处理多章节文本、调用工具，也让生成结果能够被查询、校验、编辑和继续使用。

目前主要使用 **Python** 与 **TypeScript**，持续实践 AI 编排、后端服务与 Web 产品体验。

## FEATURED BUILDS / 代表项目

### 01 / [NutriMind-Agent](https://github.com/yzh-01/NutriMind-Agent)

端到端 AI 营养分析平台：使用 YOLO11s 识别餐食，以 LangGraph ReAct Agent 编排营养查询、摄入汇总与知识库检索，并结合用户档案生成饮食与运动建议。

`Python · FastAPI · YOLO11s · LangGraph · PostgreSQL · PGVector · Vue 3`

### 02 / [Novel2Script-AI](https://github.com/yzh-01/Novel2Script-AI)

把多章节小说转换为电影、电视剧或短剧的结构化 YAML 剧本，支持角色与场景生成、分栏编辑、实时校验和导出。

`TypeScript · Next.js 14 · CodeMirror 6 · Zod · Prisma`

[查看在线 Demo →](https://novel2-script-ai.vercel.app/)

### 03 / [WINTEROMEN](https://github.com/yzh-01/yzh-01.github.io)

长期维护的个人数字花园，记录技术探索、学习过程、项目实践与普通生活。站点采用自有 Hexo 主题与原生 CSS / JavaScript，并适配深浅主题、响应式布局、键盘操作、减少动态和动画节能。

`Hexo 8 · Nunjucks · CSS · JavaScript · GitHub Actions`

[访问数字花园 →](https://yzh-01.github.io/)

### 04 / [Image2Story-AI](https://github.com/yzh-01/Image2Story-AI)

轻量的图像叙事实验：由 Gemini 分析图片的氛围、场景与感官细节，生成英文故事开篇，并通过 TTS 提供朗读。

`React 19 · TypeScript · Vite · Express · Gemini API · Motion`
